Política de Privacidade

Última atualização: novembro de 2026.

1. Quais dados são tratados

Ao conectar uma conta do TikTok via Login Kit, a ferramenta recebe um token de acesso (OAuth) e informações básicas do perfil autorizado (scope user.info.basic). Os vídeos enviados passam pela Content Posting API no modo rascunho (scope video.upload).

2. Onde os dados ficam

A ferramenta roda localmente, na máquina do próprio autor. O token de acesso é salvo apenas no computador do autor. Não há servidor próprio, banco de dados remoto nem compartilhamento de dados com terceiros.

3. Senhas

A ferramenta nunca pede nem armazena a senha da conta do TikTok. Toda autorização é feita pelo fluxo oficial OAuth do TikTok.

4. Compartilhamento

Nenhum dado pessoal é vendido ou compartilhado. As únicas transmissões ocorrem para os servidores oficiais do TikTok, conforme necessário para autorizar e enviar vídeos.

5. Revogação

O autor pode revogar o acesso a qualquer momento nas configurações da conta do TikTok ou apagando o arquivo de token local. Ao revogar, a ferramenta perde o acesso.
